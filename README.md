# Drowsiness-Detection-System
A real-time Drowsiness Detection System using CNN-LSTM and EAR. Yawn detection (Detect-Yawning Dataset) achieved 99% accuracy. EAR &lt; 0.25 for 15 frames, computed via Mediapipe FaceMesh, signals drowsiness. CNN extracts spatial, LSTM temporal features, and an alert is triggered to warn the driver.
